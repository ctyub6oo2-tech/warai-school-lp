## 実際の投稿画像にする手順

### 1. SVGをデザインツールに読み込む
Canva、Figma、Illustratorなどを開き、`slide-01.svg`〜`slide-08.svg` を順番に読み込みます。
読み込む順番がそのままInstagramカルーセルの投稿順になります。

### 2. ブランドに合わせて微調整する
必要に応じて、以下を調整してください。
- フォント：アカウントの雰囲気に合う日本語フォントへ変更
- 色：ブランドカラーや既存投稿のトーンに合わせて変更
- 署名：`WARAI SCHOOL` の表記をアカウント名やサービス名に変更
- 余白：スマホで見た時に文字が詰まって見える場合は、本文を短くする

### 3. PNGまたはJPGで書き出す
Instagramに投稿する場合は、各スライドを以下の設定で書き出すのがおすすめです。
- 形式：PNG（文字をきれいに出したい場合）またはJPG
- サイズ：1080 × 1350px
- ファイル名：`slide-01.png`、`slide-02.png` のように投稿順が分かる名前

### 4. Instagramにカルーセル投稿する
Instagramの新規投稿で、書き出した画像を `slide-01` から `slide-08` の順番に選択します。
キャプションは `content/instagram-scenario-self-change.md` の「キャプション案」を使えます。

### 5. リール化する場合
リールにする場合は、各SVGまたは書き出したPNGを動画編集アプリに読み込み、1枚あたり5〜7秒表示します。
ナレーションは `content/instagram-scenario-self-change.md` の各スライドの「ナレーション」を読み上げると、45〜60秒程度の動画にできます。

## 投稿前チェック
- 1枚目だけで「何の投稿か」が伝わるか
- スマホ画面で本文が小さすぎないか
- 8枚目に保存・見返しの理由があるか
- キャプションに保存やコメントを促す一文があるか
- 投稿順が `slide-01` から `slide-08` になっているか
